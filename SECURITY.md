# Security policy

## Reporting a vulnerability

Please report security issues privately by email to **info@eugo.io**. Do not open a
public issue for a security problem.

Include what you found, how to reproduce it, and the affected files. We will acknowledge
your report and keep you updated while we work on a fix.

## Scope

This repository contains example notebooks and tests. If you find a credential, hostname or
other sensitive value committed anywhere in it, please report it the same way.
